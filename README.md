# Note Taker

A simple demo-ready note-taking app built with React, TypeScript, and Vite.

## Features

- View a list of notes on the homepage
- Create, edit, and delete notes
- Persist notes in `localStorage`
- Clean responsive UI for stakeholder demos

## Run locally

```bash
npm install --include=dev
npm run dev
```

## Test

```bash
npm install --include=dev
npm test
```

## Build

```bash
npm run build
```
